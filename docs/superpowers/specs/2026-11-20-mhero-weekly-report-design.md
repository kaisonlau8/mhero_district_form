# 猛士周报设计

日期：2026-11-20。版式已确认：当周经营数据及同比/环比；指标按每周导出时的季度累计展示。本文件锁定实现口径，不再改版式。

## 目标

在现有区域报表导航中增加「猛士周报」。可切换周次。每周快照持久保存，重复导入相同内容视为幂等，内容不同则拒绝覆盖；只有显式「新修订」才保留旧行并另存新行。

页面上有两块适合桌面截图的中文区域：

- A. 当周经营：全国与各区域的收款工单数、总产值，以及环比上周同进度、同比去年可比周同进度。三个期间的起止日写在块内。
- B. 该周导出的季度累计 KPI：首保、二保、新保、续保，以及在样本上逐行核验过的比率。全国与区域按分子/分母加权。低于全国加权达成率的格子标红。督导原因分析默认为空，人工保存后才有字。

缺文件、缺对比写「未导入」。分母为 0 写「不可比」，涨幅不计算。不把缺数显示成 0。不写源表没有的单位、含税。不把附件样本当成当前周。

## 不在本轮

不合并、不部署、不登录生产、不读 `.env`、不联系门店、不新增或改动每日 08:30 调度、不调用 DMS、不写未授权内部接口。自动采集只留一个会明确失败的入口，并指向 `https://github.com/kaisonlau8/m-hero/blob/main/docs/SHARED_DMS_BROWSER.md` 的浏览器锁与错峰。旧日报、7 张源表、考核剔除逻辑保持原样。

## 周与三个期间

周次以周一为 `week_start`。经营文件的统计起日必须等于该周一，统计止日必须落在该周内（周一至周日）。这就是「同进度」的截至日。

- 当周：`week_start` 至截至日
- 上周同进度：两边各减 7 天
- 去年可比周：两边各减 364 天（52 周，星期对齐）

对比只认期间完全一致的已导入快照。期间对不上写「不可比」，不用错窗口的数计算涨幅。没有当前周文件时，页面只显示该周的日历范围和「未导入」，不编造截至日。

附件里的经营样本统计的是 2026-11-01 至 2026-11-19，导出日是 2026-11-20。它跨周，不能绑到任何一周。解析测试可以使用它，页面默认周不得出现这组数字。

## 经营 Excel

来源页面是服务经营报表。查询条件不在单元格里，导入时必须另填：统计类型、报表类型、统计起止、导出时间、时区。本轮只接受统计类型「收款」、报表类型「日报」。

表头（第 1 行）与样本一致。汇总行（区域名称「汇总」）是该文件的唯一合计。明细里的车辆数不能相加，也不能跨区域相加。全国文件的明细全是「全国」，不能拆成区域。单区文件只有一个区域，区域名去掉结尾「区」（华东区→华东，华中1区→华中1）。一份文件里出现多个区域则拒绝。

总产值展示汇总行，并并列工时、备件、其他。三项之和与汇总不一致时保留差额，不改写汇总。金额不标元或万元，并写明源表未注明单位与含税。

收款工单数的名称保持「收款工单数」，并注明：按收款时间与已收款工单，含仅备件销售，不是严格来厂台次。

各区用各自文件的汇总行。已导入区域的可加总字段（工单数、总产值、工时、备件、其他）与全国比较，差额和未导入区域都保留。车辆数不对平。不摊分差额。

## KPI Excel

来源是服务管理报表的通用主表（不是每日流水线那 5 份具名明细）。样本 774 行在核验后是 774 个门店编码各 1 行、周期都是「2026年Q4」，没有门店+周期重复。代码按实际行计数，不把 774 写死成门店数。若门店+周期重复，或周期不唯一，或数量单元格为空，则拒绝加权汇总并说明原因。

DMS 区域为空标「无区域」。不用门店表、多维表格或飞书改归属。全国加权包含无区域行。

季度累计：年份与季度来自「周期」列。2026Q4 的季度起日是 2026-10-01。截至日是导入时声明的日期，不是因为没有日筛选器就否定它。截至日必须落在所选周内，并且落在该季度内。页面同时展示季度起日、截至日、录入的 `exported_at`。

达成率只用分子/分母（或已核验的等价加权式），禁止对门店百分比取平均。源表自带的百分数只用来对账，不直接拿来做全国率。分母为 0 时，即使源格写成 0% 或 100%，也显示不可比。

已在 2026-11-20 的 774 行上逐行对上的指标：

| 指标 | 加权式 |
|---|---|
| 首保实施率 | 实保 / 应保 |
| 二保实施率 | 实保 / 应保 |
| 新保实施率 | 投保量 / 交付量 |
| 续保实施率 | 实续保 /（应续保 + 去年同期交付未新保车辆数量） |
| 品情活动实施及时率 | 无漏做车辆数 / 入场车辆数 |
| 投诉响应及时率 |（分钟响应量 + 小时方案量）/（2 × 投诉单量） |
| 咨询响应及时率 |（分钟响应量 + 小时方案量）/（2 × 咨询单量） |
| 综合响应及时率 | 上述四项响应量之和 /（2 ×（投诉单量 + 咨询单量）） |

总达成率、巡检得分、工装/常用备件配备率、标准化餐食、调研与 NSS 公式未核验。这些列可以记在数据质量里，不进入加权，也不显示成 0。列缺失的可选指标直接不出现，不补 0。首保、二保、新保、续保的列缺失则拒绝该文件。

区域加权达成率低于全国加权达成率时标红。相等不标红。不可比不标红。

## 督导原因

现有持久化写入是豁免/剔除申请和备件名单，都不是周报评语，不能拿来生成原因。新增 `weekly_commentary`，按周+区域保存人工文本，写入审计。初始为空。页面用「未填写」表示空，输入框 placeholder 为「待填写」，不预填句子。督导和管理员可保存；查看者只读。

## 快照

`weekly_imports` 保存解析结果和原始 xlsx（只在数据库，不进 git）。活跃键是种类 + 周一起始 + 范围。经营范围是「全国」或归一后的区域。KPI 一份文件的范围是「全国」，区域内部分区在 JSON 里。

相同 sha256 且元数据相同：幂等，不新增行。不同：`SnapshotConflict`，除非 `allow_revision`。旧行改为 `superseded` 并指向新 id，页面默认只读活跃行，历史区列出全部修订。

## 入口

- 导航「报表」下「猛士周报」，路由 `/reports/weekly?week=周一`
- 管理员导入页 `/reports/weekly/import`
- `python -m reportdb.weekly_import operation|kpi ...`
- 查看者可以打开周报，不能导入

真实整本业务工作簿不提交仓库。测试用代码生成的脱敏小表。本机若放着附件，另有一条可跳过的样本测试，只验证解析数字与「不能绑成当周」。
