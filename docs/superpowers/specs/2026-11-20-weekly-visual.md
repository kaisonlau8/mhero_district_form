# 周报怎么看

给看报表的人，不给做系统的人。

- 经营：上面三个全国大数字（收款工单数，单；总产值，元；车辆数，辆）。下面三张竖向柱图，区域名在下方，蓝柱是本期，橙柱是对比期。全国不放进各区那张图。可切「季度环比」或「年度同比」。来源只写一句：来自DMS收款报表。没导入的不画成 0。总产值单位为元（2026-11-20 确认），不换算。是否含税未注明。
- 指标：六张竖向柱图，两列。区域名在下方，橙色虚线是全国。低于全国用红色。没有分母写「暂无数据」。来源只写一句：使用系统计算结果。
- 算法、表名、导出时间明细放在默认收起的「核对」里。
- 截图入口会藏起导航和编辑框。示例页只在 `/reports/weekly/demo`，标明「示例数据，非实际经营数据」，正式周报不会拿示例填空。
