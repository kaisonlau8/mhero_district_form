# 周报怎么看

给看报表的人，不给做系统的人。

- 经营：上面三个全国大数字（收款工单数，单；总产值，千元；车辆数，辆）。下面三张竖向柱图，区域名在下方。季度图用本季度 / 上季度同期，年度图用本年度 / 去年同期。全国不放进各区那张图。来源只写一句：来自DMS收款报表。没导入的不画成 0。总产值源数据是元，页面除以 1000 显示千元，保留两位小数。涨跌按原始元计算。是否含税未注明。车辆图标题是「各区来厂车辆数（去重）」。
- 指标：一张表。行是全国和各区域，全国在第一行。列是六项自算指标。低于该项全国的数字用红色。没有数写「暂无数据」。来源只写一句：使用系统计算结果。原因在最右列，编辑框不在截图里。
- 算法、表名、导出时间明细放在默认收起的「核对」里。
- 截图入口会藏起导航和编辑框。示例页只在 `/reports/weekly/demo`，标明「示例数据，非实际经营数据」，正式周报不会拿示例填空。
